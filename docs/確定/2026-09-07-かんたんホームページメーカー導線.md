## 核心（1本）

**1画面で1つだけ考える。サンプル本線では本番プレビューを作成演出まで出さない。細かく触りたくなった人だけ、入口の「自分で作る」または完成後の「編集する」で編集ハブへ渡す。**

外向けに「AI生成」とは言わない。  
推奨表現: **「選んだ内容に合わせて文章候補を作ります」**  
営業表現（見本）: **「見本はすべてこのメーカーで作成しています。」**

文章エンジンは **相性付きパーツ組合せ**（意味検索・外部APIではない）。

---

## 分岐モデル

```
フル入口（2択）
 ├─ サンプルから選ぶ
 │     → 回転寿司（ストック最大3）→ 用途 → 色合い
 │     → 基本情報 → セクションごと文章5択 → 画像ワイヤー1画面
 │     → 作成演出 → 本番プレビュー
 │         ├─ これでいい → 確認 → ZIP
 │         └─ 編集する → 編集ハブ → 確認 → ZIP
 └─ 自分で作る → 用途 → 編集ハブ → 確認 → ZIP
```

- **途中の簡単⇄こだわり（モード変更）は廃止**
- 「編集する」の説明は **常時1行のみ**（ホバーで同内容を重ねない）  
  例: 色・文章・画像の枚数・枠の並びなどを直せます
- **ABCはユーザーに出さない**（見本データに内包された結果）

## 戻る／最初に戻す

| 操作 | 役割 |
|------|------|
| **ひとつ戻る** | 直前画面の選択・入力のみ戻す（全消ししない） |
| **最初に戻す** | 全リセットしてフル入口2択へ |

### 最初に戻すで消すもの

- 入口選択（サンプル／自分で）
- 寿司ストック・確定見本番号
- 用途・色合い・基本情報
- セクション文章選択
- 画像ファイル選択状態
- 完成プレビュー／確認手前の進行状態
- 下書き（localStorage 等）を **空の初期状態** に戻す

ZIPとして端末に保存済みのファイル本体は対象外。

## 回転寿司

- 見本が **約2〜2.5秒** でスライド（調整可）
- **ストック最大3**。4つ目は「どれと入れ替えるか」
- 流れてきた皿: 「これにする／ストック」
- ストックは上部に小さく載る。タップで **差し替え／候補から外す／確定**
- **一時停止**・**ひとつ戻る**あり
- 注記: 「このあと用途を決めます。直感で好きなサンプルを選んでください」
- 各見本は **番号付き復元データ＋全体スクショ**（モック画像だけの先行量産は禁止）

## 疑似文章作成（APIなし）

### 表面（サンプル本線）

- **セクション（枠）ごと**に常に **5案** → 1つ選択 → 次の枠へ
- 主要枠のみ（レイアウトに無い枠はスキップ）
- 全体サイトを1回で5パッケージ選ぶ方式は **廃止**

### 内部

- `選択・見本タグ・用途 → 使用可能な表現群 → 使用可能な文章型` の **相性付き**
- 全パーツからの無作為組合せは禁止
- 未入力を勝手に補完しない／誇大表現を足さない

### その場5案の重複排除（コードで判定）

1. 5案はすべて **異なる文章型ID**（skeletonId）
2. 文字列の **完全一致禁止**
3. **文頭パーツID**を5案内で重複させない
4. **締めパーツID**を5案内で重複させない

「意味的に似ているか」の自然言語判定は求めない。

## 画像（サンプル本線）

- **1画面**のしょぼいワイヤー（スクロールなし目標。位置関係のみ）
- 黒枠で選択 → サムネが黒枠と左ワイヤーに入る → 次枠が光る
- 右リストの並び替えで左も連動（本線目標）
- **±なし**（増減は編集ハブ）
- 本番プレビューへの反映は **作成演出のあと**

---

## 作成演出

- 奥へ吸い込まれる → 奥から本番プレビューがドン
- 文言は実態のみ（例: レイアウトを反映しています／文章を配置しています／プレビューを整えています）
- 「AIが考えています」等は禁止
- 尺は読める長さ（約2秒固定にこだわらない。調整可）

---

## 編集ハブ（旧・こだわり表紙）

- 到達: （1）自分で作る＝用途のあと （2）サンプル完成後の「編集する」
- 解放: 全色＋グラデ、枠の並び、色・文字・画像、枠の増減（±は1系統）、書体
- 用途のあと変更なし（変えるなら最初に戻す）
- サンプル本線中は本番プレビュー出しっぱなしにしない（ハブ到達後は見ながら直す）
