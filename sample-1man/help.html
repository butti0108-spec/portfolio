    画面の見方・進め方の基本
    ← 注文画面に戻る

    見本サイトが、できあがりのイメージです。進み方は色 → 画像 → 文字の順です。

    最初の入り口（1問ずつ）

    初めて開くと、画面全体に入り口が出ます。用途 → レイアウト → 雰囲気（色）の順で、選ぶだけで進みます（まだ決まっていない、も選べます）。雰囲気は6色か「自分で色を決める」です。6色／未定は簡単モードで画像から、自分で決めるはこだわりモードで色から始まります。用途・進め方・レイアウトはあとからメニューで変更できます。下書きの途中から戻ったときは入り口は出ません。「最初に戻す」で消すと、また入り口からになります。

    見本サイトの場所

    PCでは左側、スマホでは「見本サイト」タブに表示されます。

    見本の確認と左右の幅

    上の「表示 −／＋」でスマホ・タブレット・PCの見え方を切り替えます（幅はそれぞれ固定。左が狭くても見本は縮めず、足りない分は横スクロールで見ます）。中央の縦線は、作業用に見本と注文の広さを変えるだけです（端末表示とは別です）。注文側を広げると、用途などの選択肢が横に並び、縦スクロールが減りやすくなります。

    「はじめに」ボタン

    注文画面のタイトル横にある「はじめに」から、用途やレイアウトなど最初の設定へ戻れます。

    ボタンの意味

    • 色・写真・文字・書体 … 選んだ／書いたその場で見本サイトに反映されます。
    • 次へ … 用途・進め方では「選んで進む」。それ以外（ガイド）ではこの項目を完了（緑）にして次へ進みます。
    • 確定 … セルフでは1項目を完了（緑）にするボタンです。
    • これで確定（色1のみ） … 色2〜10をまとめて完了にし、画像の選択へ進みます。

    進捗バーと番号

    色つき番号が緑になると、その項目は完了です。上の進捗バーの番号をタップすると、該当項目を開けます。PCでは番号にマウスを乗せると、「色2・ヘッダー背景」のように項目名が出ます（スマホでは見本サイト上の「番号」オンで番号を出せます）。

    用途を選んだあと

    用途を選び「次へ」を押すと、左の見本サイトに仮の文が入ります。入力欄は空のまま灰色の例文が出ます。一文字でも書くと、左はその内容に切り替わります。そのあと進め方（ガイド／セルフ）を選ぶと、すぐに進みます。「← 入り方に戻る」で、最初の入り口（イメージ／用途の二択）に戻れます。

    レイアウト（枠セットと並び）
    ← 注文画面に戻る

    最初の流れ、またはメニューから枠の種類（A／B／C）を選びます。枠の並びは、メニューの大きなワイヤーをドラッグして入れ替えできます。見本にすぐ反映します。

    A 横長

    横いっぱいの枠だけを縦に積みます。写真も帯のように広がります。

    B 左右分割

    枠を左右に割って並べます。同じ大きさどうしをドラッグで入れ替えできます。

    C 混合

    横長の枠と、左右分割の枠を混ぜます。同じ大きさどうしだけ入れ替えできます。

    枠の並びを入れ替える

    1. メニューの「レイアウト」を開く（そのまま大きなワイヤーが出る）
    2. A／B／Cを選ぶ
    3. ワイヤーの枠をドラッグし、同じ大きさの枠の上で離す
    4. 見本にすぐ反映する。動かした枠へ見本もスクロールする
    5. 「完了」で閉じる。「並びを最初に戻す」で初期順に戻せる

    ワイヤーの番号について

    カード内の「色2」「画像1」「文字7」などは、注文画面の進捗バー・見本の番号と同じ番号です。横に見比べると、どこを直す項目か分かります。

    スマホ・PCで見え方が違うとき
    ← 注文画面に戻る

    端末の見え方の確認と、作業用の左右幅は別操作です。実機と完全に同じにはならない場合があります。

    表示（−／＋）

    見本の確認用です。スマホ → タブレット → PC と段階で切り替えます。いまの段階名とピクセル目安が横に出ます。

    中央の縦線

    見本を広く見るか、注文を広く操作するかの作業用です。ここを動かしても「表示」の段階は変わりません。

    上を閉じる／進捗を閉じる

    入力スペースを広げたいときに使います。同じ場所をもう一度押すと戻ります。

    実機と違うことがある理由

    • 端末の画面サイズ・向き・拡大率
    • ブラウザの種類や表示設定
    • 写真の枚数・文字の量・選んだレイアウト

    並びや余白が少し変わることがあります。見本は完成イメージの目安です。

    番号のオン／オフ
    ← 注文画面に戻る

    見本サイト上の色つき番号の表示を切り替えます。

    オン

    見本の上に、色・画像・文字の番号が出ます。進捗バーやレイアウトの「色2」「画像1」などと同じ番号です。どこを直すか探すときに使います。

    オフ

    番号を隠して、できあがりの見た目に近づけます。最初はオフです。

    途中保存・消えたとき
    ← 注文画面に戻る

    途中までの内容は、このブラウザに自動で残ります。写真だけは残りません。

    • 別のブラウザ・別の端末では引き継がれません。
    • 同じブラウザなら、ページを更新したり、タブを閉じてあとで開き直したりしても、文字・色・進み方は残ります。
    • 写真だけは残りません。更新・開き直しのあとは選び直してください（注文画面上にも注意が出ます）。
    • サーバーへ自動送信はしません。内容は端末内だけです。
    • 最初に戻す … 入力をすべて消して、入り方の選択からやり直します（元に戻せません）。
    色の直し方
    ← 注文画面に戻る

    色は、選んだその場で見本サイトに反映されます。

    基本の選び方

    基本は「色を選ぶ」で12色から選び、必要なら濃さを調整します。左が薄め、右が濃いめです。ガイド付きの「12色で自分で選ぶ」も、同じ丸い色ボタンと濃さバーで選べます。

    カラーコードで指定

    そのときは見本サイトでは仮に白くなり、納品時に指定の色へ反映します。形式の正誤は画面では問いません。

    プリセットとランダム

    雰囲気プリセット（簡単6色。こだわりでは同じ6色＋ランダム）から選べます。こだわりでは「直したい場所の色」を押して色選択画面へ。背景色では同じ画面でグラデ向きと相手色も選べます（濃さバーはありません）。文字色ではグラデ不可と表示されます。戻るときは「この色にする」だけです。

    ガイドの色1

    下の色2〜10をタップして直したいところだけ調整できます。全体OKなら「これで確定」で次へ。1色ずつ全部触る必要はありません。

    セルフ

    色2〜10を1項目ずつ開いて確定できます。項目一覧は、全部閉じた一覧（表ではありません）から開きます。

    写真の入れ方
    ← 注文画面に戻る

    写真を選ぶと、その場で見本サイトへ反映されます。

    枠と切り抜き

    枠の形に合わせて自動でトリミングされます。重要な被写体は、できるだけ中央付近に写してください。

    別の写真に変える

    もう一度選び直してください（上書きされます）。

    目安の比率

    キャッチ約16:9（横長）、見本枠1約4:3、見本枠2のカードは横長の枠です。帯写真レイアウトでは、枠1・枠2の写真が横長の帯になります。

    枚数と必須

    キャッチ画像など1枚の項目は、写真がないと「次へ」は押せません。枚数を選べる項目は、選んだ枚数ぶん必要です。足りないままだと、依頼ファイル（ZIP）も保存できません。

    大きさ

    取り込み時に送信用の大きさへ自動で整えます。依頼ファイルは、おおむね20MB以内を想定しています。

    文字・書体の入れ方
    ← 注文画面に戻る

    書けば左の見本に反映されます。話題ごとに下の見出しを見てください。

    共通 文字数

    各入力欄には文字数の上限があります。欄の下に「いまの文字数 / 上限」が出ます。上限ちょうどまでは入力できます。上限を超えたままだと、「次へ」には進めません。

    文字2〜6 書体

    書体は見出し・キャッチ・本文の3つから選びます。12種類にない書体は、提出の任意の追記で対象を選び、書体名を入力してください（近いもので調整する場合があります）。

    仮の文と入力

    用途を選ぶと、左の見本サイトに仮の文が出ます。入力欄は空欄のまま灰色の例文です。一文字でも入力すると、左はその入力に切り替わります。

    ＋／−（行数・枠の数・枚数など）

    見本に出す数を変えます。増やすと、下に記入欄が増えます。画像の枚数・カード件数は、選んだ数ぶんすべて必要です。

    文字7 見本枠1の内容

    1つだけならそのまま入力します。複数に分けたいときは全角の「／」で区切ります（例：【強み】説明／【実績】10年）。

    【見出し】のあとに本文を書くと、見本でラベル付きになります。折りたたみブロック自体を増やすのは「アコーディオン数」の＋／−です（内容の／区切りとは別）。

    文字8 見本枠2

    カードの数は「画像3. 見本枠2の画像」のカード件数で変わります。

    文字9 住所・追加ブロック

    出すを選ぶと、見本の住所は Googleマップを開くリンクになります（別タブ）。地図の埋め込み（ページ内に地図を表示）は含みません。チェックした項目だけ、見本と記入欄に出ます。

    カードにリンクを付ける
    ← 注文画面に戻る

    見本枠2のカードごとに、外部サイトやSNSへのリンクを付けられます（任意）。

    • リンク先のURLを入れたカードだけ、ボタンが出ます。
    • ボタンの色は色8・アクセントと同じです。
    • リンクの文字（例：Instagramを見る）も任意です。
    • 入力は「文字8. 見本枠2」の項目で行います。
    ZIPの保存と送り方
    ← 注文画面に戻る

    色・文字・画像の指定を1つにまとめた提出用のファイルです。保存＝送信ではありません。

    保存と送信は別

    パソコンに保存するだけです。保存したあと、案内されたメールや返信先に自分で添付して送ってください。送るまで、制作の依頼は始まりません。

    いつ保存できるか

    すべての必須項目が完了すると、保存ボタンが押せます。

    提出の流れ

    プランの確認チェック（5項目）→ 内容の確認 →「この内容でOK・ZIPを保存する」で保存します。確定後に直したいときは「変更する」→直す→「修正」→同じボタンで再保存できます。

    含まれるもの

    • 公開後の継続更新・保守
    • 2回目以降の無料修正（別料金）
    よくある質問
    ← 注文画面に戻る

    問い合わせフォームは付きますか？

    付きません。メール掲載とコピーできるところまでです。

    直しは何回まで？

    1回まで（納品後30日以内）。2回目からは別料金です。

    文章を書いてもらえますか？

    書きません。お客様の原稿を載せるプランです。

    納品の目安は？

    内容確認後、およそ1〜2週間です（日付の指定は不要です）。

    住所は地図付きになりますか？

    ページ内に地図を埋め込むことはしません。住所を出す場合は、住所文をタップするとGoogleマップが開くリンクにします。

    サーバー代は含まれますか？

    含まれません。公開先の契約はお客様側です。

    見本と自分の端末で見え方が違います

    端末やブラウザによって、並びや余白が少し変わることがあります。くわしくは スマホ・PCで見え方が違うとき を見てください。
