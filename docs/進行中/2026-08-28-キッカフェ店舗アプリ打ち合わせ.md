## 打ち合わせで出た機能

| 機能 | 内容 |
|------|------|
| **スタンプカード** | 来店回数に応じた割引 |
| **会員証** | 月額会員を提示する画面 |
| **イベント・ニュース** | 今月のキャンペーン・イベント告知 |
