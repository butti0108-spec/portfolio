    進め方

    はじめに保存方法を選び、次に進め方を選びます。

    保存のしかた

    端末に保存せず進むと、ページを更新したときに写真が消えることがあります。文章などはブラウザの中に残ることがあります。

    残さず、そのまま作る

    保存せず、そのまま作ります。

    このパソコンに残して続ける

    この端末に保存して続けます。変更のたびに端末内のデータを上書きします。当社のサーバーには保存されません。

    進め方

    見本から選ぶ

    自分で作る

    保存したデータから再開する

    途中でこの3つを切り替えるメニューはありません。

    はじめからやり直す場合は、「最初からやり直す」を選びます。入力した内容はすべて消え、元に戻せません。

    見本から選ぶ場合の流れ

    見本 → 利用用途 → 記載項目 → 配色 → ホームページタイトル → このあとの進め方 → キャッチ → 画像 → 文章 → 色調整 → 確定。

    「このあとの進め方」は、進捗の項目ではありません。タイトルのあと、自由に編集へ移るための案内です。

    「キャッチ」を選んだ場合のみ、キャッチの設定画面が表示されます。選んでいない場合は、案内の次が画像です。

    自分で作る

    見本は選ばず、基本のページをもとに、自分で内容を決めて作ります。利用用途から始まります。

    文章は空の欄から書けます。文章例も出せます。

    確定

    確定の画面には「直したいところがあれば、上の進捗バーの文字から行けます。」と出ます。

    入っていない写真は「ここがありません」と出ます。見本のままになっている写真や文章も、確認事項として表示されます。

    「確認へ進む」ボタンを押します。

    確認へ進んだあと

    作成データを保存する

    制作・公開を依頼する

    依頼ファイル（ZIP）をメールに添付してご送信いただきます。

    「選択を変更する」で、この2つを選び直せます。

    月額制のホームページ作成サービスは、ご自身で継続して更新したい方に適しています。

    当工房の基本プランは、制作・公開を1回の料金でご依頼いただく形です。

    名前や用件を書いて送る欄や、公開後の継続更新・保守は、基本プランに含まれません。メールアドレスの掲載と、コピーできるところまでは含まれます。独自ドメイン、独自レイアウト、WordPress、サポートは、追加の有料オプションとして選べます。

    よくある質問

    無料修正は何回ですか？

    無料修正は、公開後1か月以内に1回です。それ以降は別料金です。

    公開のURLは何ですか？

    基本プランでは、GitHub Pagesを利用します。

    ご自身のドメインや、取得と管理の依頼は、追加希望で選べます。

    もっと変えたいときは？

    追加の有料オプションをご確認ください。独自レイアウト、WordPress、各種サポートなどを選べます。

    パソコンが苦手でも大丈夫？

    操作に迷ったときは、このヘルプから必要な項目をご確認いただけます。

    ご自身での操作が難しい場合は、オンライン・訪問サポートもご用意しています。

    確認とZIP

    制作・公開をご依頼の場合は、以下の順に進みます。

    ご注文前の最終確認

    チェックは次の5つです。

    基本プランのホームページは、GitHub Pagesを利用して公開します。

    名前や用件を書いて送る欄は付きません。メールアドレスの掲載と、コピーできるところまでです。

    公開後の継続更新・保守は基本プランに含まれません。

    送られてきた画像や文字に誤字脱字や間違いがあっても、確認や編集はせず、送られてきた情報のまま掲載します。

    公開後1か月以内の無料修正は1回までです。

    URL、独自レイアウト、WordPress、サポートを選べます。

    文章

    文を書く

    文章の画面で、掲載する項目の文章を入力します。

    「文章例を出す」で、参考の文章例を出せます。文章例は参考で、直して使えます。

    見本から選ぶ場合は、見本の文章を、ご自身の文章に変更します。

    自分で作る場合は、空の欄から書きます。

    枚数、すき間、順番

    文章の画面で、項目を開くと変えられます。

    枚数

    すき間は、狭い、ふつう、広い、から選びます。

    項目が2つ以上あるときは、⋮⋮で順番を変えられます。
