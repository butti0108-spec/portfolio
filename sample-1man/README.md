# 1万円プラン（注文画面）

左が**サンプル画面**、右が**注文画面**。**色 → 画像 → 文字** の順。目的は入力。

表示方針の正本: `docs/進行中/2026-09-05-注文画面表示設計.md`

## 画面

- **起動時**: 全画面入り口で用途→レイアウト→雰囲気を1問ずつ選択（未定可／自分で色を決める可）。6色または未定は簡単で画像1＋タブレット開始。自分で決めるはこだわりで色1（白紙）開始。用途・進め方・レイアウトはメニューへ。下書き進行中は入り口を出さない。
- **最上段**: 番号オンオフ／表示切替（左）・メニュー（右。中にレイアウト・最初に戻す）
- **表示 −／＋**: 端末幅は固定（390／768／1200）。左が狭くても縮めず横スクロール
- **ペイン**: サンプル画面｜注文画面（注文が広いと用途などを多列にして縦を詰める）
- **注文ヘッダー**: はじめに｜注文画面（中央）｜進捗を閉じる・ヘルプ
- **はじめにの流れ**: （通常）用途 → **レイアウト必須** → 進め方／（イメージ）仮当て後は進め方へ
- **レイアウト**: ステップ＋メニュー。A横長／B左右分割／C混合。メニューのワイヤーをドラッグして並べ替え（見本に即反映）

- **中央縦線**: 作業用の左右幅（表示切替とは別）
