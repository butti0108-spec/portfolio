## 目的

```text
見る → 気になる → 編集する → これで確定（draft.json） → 次を見る
```

## 入口

1. `http://127.0.0.1:PORT/sample-1man/index.html?review=1`
2. 編集ハブのカード **「レビュー」**（`localhost` のときだけ表示）→ 上記へ遷移

## 操作

| 操作 | 内容 |
|------|------|
| 前へ／次へ／再読込 | 見本を連続確認 |
| 編集 | レビューから一時的に編集ハブへ（作業場） |
| これで確定 | いまの状態を `sushi-samples/{folder}/draft.json` に上書き → レビュー再表示 |
| 承認（スクショ） | preview.png／STATUS（別用途。正本更新の本線ではない） |
| NG | 要修正／本NG |
| JSON（サブ） | 読み込み／共有パック書き出し。本線ではない |

## 保存先の分離（重要）

| 役割 | 対象 | 保存先 |
|------|------|--------|
| 見本確定 | 編集中の見本 | `sushi-samples/NN-*/draft.json` のみ（`__draft-save`） |
| 客データ読込 | `order.json` 等 | メモリ表示のみ。見本フォルダには書かない |
| 共有パック書き出し | `kind: sample1man-studio-pack` | ダウンロードのみ |
