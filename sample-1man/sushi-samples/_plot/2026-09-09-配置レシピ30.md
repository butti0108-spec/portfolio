# 見本30・配置（A寄せ＋大／小 sizes）

日付: 2026-09-10  
前提: 見本は **レイアウトA（全幅）**。写真・カードは `sizes`（L=全幅／H=半幅）。B／Cは見本では使わない（ハブのABC種火は残可）。

## sizePat

| 記号 | 意味（枚数に合わせて調整・末尾余りHはL） |
|------|------------------------------------------|
| S1 | すべて L（隙間 loose） |
| S2 | HH のあと L… |
| S3 | L のあと H…（例: LHH / LHHL） |
| S4 | できるだけ H（隙間 tight。3枚は HHL） |
| S5 | 3枚は LHH／4枚は LLHH（隙間 loose） |
| S6 | LHH または LHHL |

## 反映

- `migrate-a-and-sizes.ps1` → 全30 `layoutPattern=a` + `itemLayouts.sizes`
- `sync-meta-layout-a.ps1` → materials meta も a
- エンジン: `script.js` の L/H（余り末尾H→L、2枚目H時は1枚目もH）
- CSS: Aでも `.is-item-layout-manual` が2列グリッド優先

## 監査

```powershell
Get-ChildItem ..\..\*\draft.json | ForEach-Object {
  $j = Get-Content $_.FullName -Raw -Encoding UTF8 | ConvertFrom-Json
  "{0} {1} photo={2} works={3}" -f $j.sushiSampleId, $j.layoutPattern, ($j.itemLayouts.'about-photos'.sizes -join ''), ($j.itemLayouts.'works-list'.sizes -join '')
}
```
