# アーチデザイン工房 — 屋号・ロゴ

日付: 2026-09-11  
状態: 確定（運用ルール）

## 屋号

- **日本語**: アーチデザイン工房
- **ローマ字表記**: ARCH DESIGN KOBO（カタカナ屋号のローマ字。正式な英語社名ではない）
- **アーチ**: 上向きの弧（虹・門・扉などのイメージ）。「Archie」ではない

## ロゴ使い分け

| 用途 | 使い方 |
|------|--------|
| ファビコン | 文字なし。A＋虹＋水平線のみ（`mark-only`） |
| ヘッダー等 | マーク＋屋号一式、またはマーク（水平線まで）＋横に同系書体で屋号 |
| カラー／モノクロ | 両方マスターを持つ |

## マスター配置

`sample-1man/brand/`

- **表示の正**: `logo-color.png`（共有画像そのまま）
- `mark-favicon.png` … ファビコン／小アイコン
- `mark-only.png` … マーク切り出し
- 旧SVGは参考残置（見た目合わせの本線には使わない）

虹のにじみ等は整形してからマスター化する。
