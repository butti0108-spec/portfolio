## 対話の経緯（どうこの設計になったか）

### 1. きっかけ：左の番号の違和感

- **現象**: 左プレビューで「9｜8」「11｜10」のように、左の数字の方が大きい。上から1,2,3…とも並ばない。
- **気づき**: 右パネルは0〜17の**通し番号**、左は**場所に散らばったバッジ**。同じ数字体系なのに空間順と一致しない。
- **方向**: ペアは**左→右で番号昇順**。後に **色/文字の二系統番号** へ。さらに **色／画像／文字の三系統** へ。

### 2. ウィザード／アンケート型への転換

- **増渕さん案**: 右に全部見せない。はじめに→1問ずつ→次へで確定→左が育つ。最後に確認→ZIP。修正は左タップ。
- **クル**: 既存の `confirmStep`・左バッジ・ZIP と相性良い。右のフロー一覧は非表示でよい。
- **試作**: ウィザード骨組み（localStorage **v7**）、プリセット必須・ランダム履歴2段。

### 3. 「選ばせる」と「気づかせる」の転換

- **最初の仮説**: 方向性を先に決めればミスがない。
- **増渕さんの修正**: 作り始め時点では**本人も分かっていない**ことが多い（メガネレンズ作りと同型）。
- **結論**: 正解を先に選ばせず、**触った結果として自分のサイトが残る**。入口はどこからでもよい。漏れは**最後に1回**。

### 4. メガネ検査メタファー（色決めの本命）

- **体験**: 「前と後、どっち？」の**二択**→一項目ずつ確定→試着→部分修正も再び二択。
- **適用**: **色だけ**メガネ式。**文字・画像**は本人入力。
- **入口**: ガイド／セルフの**モード選択は1回**。明確な人は次へ連打・一覧スクロール。

### 5. 2モード＝情報密度の正反対

| ガイド | セルフ |
|--------|--------|
| 情報最小・大文字・余白多 | 説明削減・カテゴリ圧縮・縦スクロール一気 |
| 丸ゴ・戻る大きめ・安心 | 角張り・戻る｜次へ同格 |
| 1問ずつ | 色→画像→文字を一覧で好きな速度 |

### 6. UX摩擦の除去

- **次へ** … 戻ると**同サイズ・同色**（セルフ）。ガイドのみ戻る大きめ可。
- **毎回の confirm** … **廃止**。次へ＝**黙って確定**（バーの該当番号が緑）。
- **章境目** … 全面オーバーレイなし。上バー＋応援1行（「あとN問」）。**所要時間は出さない**。色→画像／画像→文字で応援1行。
- **提出** … チェック5項目 → **提出の確認** → **ZIP（最下）**。全面オーバーレイなし。
- **説明の正本** … 1万円ページ・ポートフォリオFAQへリンク。はじめにFAQは削除。
- **JSONコピー** … 削除（ZIP内 `order.json` で足りる）。

### 6b. 上固定・進捗バー（2026-08-29 確定 → 三章に更新）

- **色9＋画像5＋文字8** の番号マス。薄青／橙／薄赤 → **次へで緑**。タップでジャンプ。章のあいだにギャップ2つ。
- **現在、色3 編集中（帯）。あとN項目で完成。** の順（現在地→番号→完成まで）。
- 応援1行は短く。ZIP不可時は未緑マスを強調。
- 公式用語：**サンプル画面**／**注文画面**／**依頼ファイル（ZIP）**。「左」「プレビュー」はお客様向けに使わない。
- お客様向けの説明：**色はすぐサンプル画面に出ます。画像・文字は「次へ」のあと、こちらに反映されます。**
- 書体選択は**カード一覧**（各カードがその書体の見本）。プルダウンは使わない。
- 提出：戻る＋案内 → 提出の確認 → フッターに大きな「依頼ファイルを保存」。
- **ヒーロー中央に大きく「これは見本です」のみ**。
- ヘッダーは**本物メニューに見せない**。空のときは注釈を**2段**。
- 進捗行も**2段**（現在地／あとNで完成）。凡例は青＝色／橙＝画像／赤＝文字。
- サンプル画面のダミー文は**中立プレースホルダ**。
- 斜め SAMPLE は **アップロード画像のみ**。

### 7. 色のフィードバック

- **コントラスト警告** … 廃止（好みの否定になりやすい）。
- **将来**: 物差し（●のみ）＋触った結果の「寄り」表示（事前の方向選択はしない）。

### 8. 左バッジ：青／橙／赤／緑

- **色** … **青** 1–9
- **画像** … **橙** 1–5
- **文字** … **赤** 1–8（追加＝7・提出＝8）
- **確定後** … **緑**

### 9. 3章・保存・安心

- **第1章・色** → **第2章・画像** → **第3章・文字**（末尾にその他＝追加・提出）
- ガイド: `guidedImageUnlocked` / `guidedTextUnlocked` で後章ロック
- **下書き全削除**ボタン（提出付近）。「初期色に戻す」とは別。下書きキー `sample-1man-order-v7`
- **「あとから直せます。気軽に選んでください。」**

### 10. ガイド第2〜3章 — 2026-08-29 確定

- **表記・入力項目はセルフと同じ**（同じ `dash-block` 中身）。
- **レイアウトだけガイド向け**（大文字・余白・1問ずつ提示）。
- 色ほど二択にはしない。

### 11. 章分けの実務ルール（v7）

- **Works件数 (+/−)** … 画像章 `works-images` のみ。文字章 `works-text` は件数UIなし（`data-fill-for="works-list"` で同期表示）。
- **About写真枚数** … `about-images`。アコーディオン数は `about-text`。
- **SNS** … 画像章 `sns-links`（件数＋URL）。
- **その他** … `extra-content`（営業時間／アクセス／地図のONと文）→ そのあと `finish`。
