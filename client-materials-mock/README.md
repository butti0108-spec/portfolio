# お客様向け資料モック

増渕ポートフォリオ（https://ai-shin-ka.com/）を「納品したお客様サイト」と仮定したサンプルです。

## 開き方

`index.html` をブラウザで開く。

## 中身

| ファイル | 内容 |
|----------|------|
| `01-proposal.html` | ご提案書（スクショ＋進め方イラスト） |
| `02-operation-guide.html` | 操作案内（カスタマイズ／Work／フォーム） |
| `03-handover.html` | 納品お渡しチェック |
| `04-estimate-mail.html` | 見積メール文例 |
| `images/` | 本番スクショ＋生成イラスト |

## 注意

契約書・正式見積ではありません。実案件では社名・金額・範囲を差し替えてください。
