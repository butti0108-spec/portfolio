# 操作UIレイアウト仕様

- **状態**: 確定（2026-09-27・敦さん合意）
- **用途**: これから作る色や文字などの操作UIの参考
- **基準**: 画像登録の画面そのものではなく、その画面を作った考え方

---

## 考え方

- 画像の画面の部品は、他のセクションへコピーしない。
- 左から、決める順に置く。
- 関係のある操作は近づけ、別の操作とは間を空ける。かたまりの中より、かたまりのあいだを広くする。
- 項目の名前だけを大きく、太くする。操作の文字は同じ大きさに揃える。
- 開いた中の文字は、その項目の名前より大きくしない。
- 書体は変えない。
- 案内は全部残す。並びを見れば、案内を読まなくても操作が分かる。
- 同じ意味の操作は、同じ見た目にする。
- 色と文字の具体的な部品名は書かない。その画面を作るときに決める。

---

## 枠で囲んだパネルの余白（2026-09-29 追記）

- **寄せ**: 枠の中は上寄せ。縦の中央寄せにしない（特別な理由があるときだけ例外）。
- **枠の上余白**: **0.75〜0.95rem**（目安 **0.85rem**）。文章候補カード・必須入力枠・画像ワイヤーの開いた枠に揃える。
- **これから**: 文章工程・確定画面など、枠で囲む操作UIを直すときも同じ。理由なく大きく空ける／画面ごとに変えない。
- **参照実装**: `sample-1man/sample-overrides.css` の `.easy-copy-card-inner`（0.75rem）、`#easy-img-layout-host.is-section-solo` / `.is-photo-solo` の開いた cell（0.85rem）。
