# sushi-samples ツリーの役割

このフォルダは「1万円メーカー用の見本30」関連です。  
**名前は後から変えてよい。配置の役割だけ固定する。**

## 4つの置き場

| 場所 | 役割 | WP・営業に上げる？ |
|------|------|-------------------|
| `01-…`〜`30-…/` | **製品が読む**（`draft.json` / `preview.*`） | 採用後の preview のみ検討 |
| `_plot/` | **設計の正本**（30の狙い・品質・項目） | いいえ |
| `_materials/` | **制作材料**（文面・写真・出典・メモ） | いいえ |
| `_sales/` | **営業・確認用の完成パック** | はい（完成後） |

ルートの `manifest.json` は寿司UIが読む一覧です。

## 状態の流れ（1件ずつ）

1. `_plot` の行を確認  
2. `_materials/NN-…/` に文面・写真を揃える  
3. `NN-…/draft.json` に反映してプレビュー確認  
4. 採用したら `preview.png` を置き、`_sales/packs/NN-…/` へコピー  
5. `_materials/STATUS.md` を更新  

## 置かないもの

- ブラウザ検証プロファイル（`sample-1man/_verify-tmp/` など）→ 製品ツリーに混ぜない  
- 不採用の連写PNGの置きっぱなし（採用分だけ `preview.png` / `_sales`）

## 品質目標

パッと見「え、どこの店？」レベル。よく見ると架空だと分かる。  
詳細は `_plot/quality-bar.md`。
