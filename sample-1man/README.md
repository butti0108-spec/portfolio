# サンプル工房（1万円プラン・盛り盛り試作）

左プレビュー＝納品イメージ。**1作業＝1アコーディオン**（他は自動で閉じる）。

## 画面

- **左**：見本。番号／場所タップで右の該当入力が開く（双方向連動）
- **右**：0〜16のフラットなアコーディオン（同時に1つだけ開く）
- 色はすぐ反映／文字・書体・画像は確定後
- 入力は灰色プレースホルダー。取り消し・訂正で欄を空に戻す
- スマホ：左タップ時は注文タブへ自動切替

## 番号の目安

| 番号 | 内容 |
|------|------|
| 0 | はじめに |
| 1–6 | 全体色（プリセット〜カード） |
| 7 | 全体・文字／ロゴ |
| 8–9 | キャッチ色／文字・画像 |
| 10–13 | 枠・About・Works・追加 |
| 14–15 | ご連絡色／文字 |
| 16 | 提出 |

## 保存

`localStorage` キー `sample-1man-order-v4`（画像は復元不可）

凡例: **青＝色（確定なし）**／**茶→緑＝文字・画像**。左の番号は表示幅の横でON/OFF。丸は効く場所の近くに配置。

## 開き方

`sample-1man/index.html` をブラウザで開く（`../style.css` が必要）。
