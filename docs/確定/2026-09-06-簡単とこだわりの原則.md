## 核心（最重要）

**「こだわれること」と「動線の分かりやすさ／無駄な動きをさせない」は別の話である。**

- 細かく触れるからといって、機能を何でも入れればよい、ではない。
- **触れる中身は厚くてよい。操作の道（入口・戻り・常時UI）は細く保つ。**
- **1画面で1つだけ考える。** サンプル本線では選択肢を増殖させない。

## 役割の分け方（2026-09-07 夜 以降）

途中の「簡単⇄こだわりモード変更」は **廃止**。

| 呼び方 | 意味 |
|--------|------|
| **サンプルから選ぶ** | 入口2択の一方。回転寿司で見本を掴む→用途→色→文章→画像→作成演出→出す／直す |
| **自分で作る** | 入口2択の他方。用途のあと編集ハブへ |
| **編集する** | サンプル完成後の分岐。編集ハブへ（常時1行説明のみ） |
| **編集ハブ** | 旧・こだわり表紙（枠の並び・個別色・書体・画像増減など） |

### サンプル本線

詳細は導線正本。要約:

フル入口 → 回転寿司（ストック3）→ 用途 → 色合い → 基本情報 → セクションごと文章5択 → 画像ワイヤー1画面 → 作成演出 → 本番プレビュー → これでいい／編集する → 確認・ZIP

- 本番プレビューは作成演出まで出さない
- ABCはユーザーに出さない（見本データに内包）
- 画像±なし（増減は編集ハブ）
- 書体は見本／既定。編集ハブでは文字入力の場で役ごとに1つだけ変更可（まとめ入口なし）
- ひとつ戻る／最初に戻すを分離（定義は導線正本）
- 見本30は本システム制作（モック画像だけの先行量産禁止）

### 編集ハブ（自分で作る／編集する）

- 到達: （1）自分で作る＝**用途選択のあと** （2）サンプル完成後の「編集する」
- 解放: 全色＋グラデ／枠の並び／色・文字・画像／枠の増減／写真・カードの向きと隙間／書体（文字画面で役ごと）
- **キャッチ写真の文字**: サンプル本線は載せない。編集ハブで「載せる／載せない」＋下地形（四角／角まる／楕円）＋下地色（白／暗い）。文字色は下地に合わせて自動
- 右パネル上から: **ABC種火 → プレビュー表示（幅）→ プレビュー鏡ワイヤー**
- ワイヤー見出しはプレビュー上の見出し文言をそのまま使う
- ABC切替は骨格のみ。文字・写真・色など中身は残す。薄い注意のあと自分で調整
- レイアウト系は一手ずつ Undo 可（最初に戻すとは別）
- 緑枠に表紙出しっぱなし（ハブ到達後）。用途のあと変更なし（変えるなら最初に戻す）
- 配色プリセット6の再掲はしない
- サンプル本線は触らない

### 枠の増減（編集ハブ）

- **±は枚数用に1系統**（縦用±・横用±の二本立てにはしない）
- **写真・カード**で＋するとき（2枚目以降）: **「大きい／小さい」の二択**（大＝全幅一段、小＝半幅。2枚目を小にすると1枚目も小になる。末尾の余り小は大に強制）
- **隙間**: 狭い／ふつう／広い（ブロック単位・離散3択）
- サンプル本線には出さない（増減・大小・隙間は編集ハブのみ）
- 配置の破綻は基本ルールで機械的に決まる（余り小の空マスは自動で大へ）
- 見本は全幅（A）中心。B／C半幅は見本では使わない
- 色編集はハニカム。旧スウォッチ／進捗バー／セルフ一覧など残骸は残さない

### 品質の先出し（1万円プラン）

- **「1万円だからこの程度」は禁止**
- 作れるだけ作り込み、確認できることは先に確認する
- 営業: 「見本はすべてこのメーカーで作成しています。」

### 画面幅

- 点々メジャー型。ラベルは「プレビュー表示」
- 入口・選択画面は中央の細い帯で窮屈にしない

### 廃止したもの（残さない）

- 透過エントリーゲート本線（用途→モード→雰囲気→レイアウト）
- いつでも切替の「モード変更」
- 旧かんたん本線（ABC明示・入口配色6・全体文章5案・画像3画面分割）
- メニュー本体・番号オンオフ・進捗バー本線・セルフ一覧

ヘッダー右は **赤い「最初に戻す」**。ヘルプは chrome 上部。
