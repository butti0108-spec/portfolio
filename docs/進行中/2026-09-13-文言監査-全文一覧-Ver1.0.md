# 文言監査-全文一覧 Ver1.0

- 日付: 2026-09-13
- 対象: sample-1man（かんたんホームページメーカー）
- 役割: **画面文言（UX）の正本**
- 範囲: ユーザーが見る画面の文言のみ。候補文章の中身は別紙。
- 方針: リライトなし・原文のまま・漏れなく抽出
- 監査段階: **第1段階＝画面文言監査**（第2段階は候補辞書別紙）

## 使い方

- 画面を `#`、UI種別を `##`、各文言を `-` で列挙。
- 同一文言が複数画面にある場合は `（○○画面でも使用）`。
- 動的差し替えは候補を列挙し、必要なら「動的」と注記。
- 文章5案の**本文**は載せない。UI枠のみ「文章候補（5案）」。

## セクション：画面の見方・進め方の基本

- 画面の見方・進め方の基本
- 入口は2つだけです。「サンプルから選ぶ」か「自分で作る」か。
- 最初の入り口（2択）
- 初めて開くと、画面全体に入り口が出ます。サンプルから選ぶか自分で作るかを選びます。途中でモードを切り替えるメニューはありません。やり直すときは「最初に戻す」です。
- サンプルから選ぶ（本線）
- 回転寿司で見本を見て、「ストック」か「これにします」で1件決めます（ストックは最大3）。
- 用途 → 色合い（見本のまま／色だけ変更）を選びます。
- 基本情報 → 枠ごとの文章（5案から選ぶ）→ 画像ワイヤー → 作成演出 → 本番プレビュー。
- 「これでいい」で確認・ZIPへ。「編集する」で編集ハブへ。
- 選択・入力のあいだは本番プレビューを出しません。
- 自分で作る
- 用途を選んだあと、編集ハブ（並び替え）へ進みます。色・文字・画像・枚数の増減を自分で触れます。
- 戻る操作
- 一つ前の作業に戻す … 直前の編集操作を取り消します。
- 並びを最初に戻す … 枠の順番だけ初期に戻します。
- 最初に戻す … 進行データをすべて消し、入り口の2択からやり直します。

## セクション：なぜ1万円か

- なぜ1万円か
- 簡単なホームページを、簡単に
- このプランは「何でも複雑なサイトを安く」ではなく、簡単なホームページを、簡単につくるためのものです。判断材料として、切っている範囲をはっきり見せます。
- 月額ツールとの違い
- 月額のホームページツールは否定しません。ずっと自分で触りたい人には向きます。こちらは一度つくって納品する形で、フォーム常設や無制限の直し、独自ドメイン運用などは切っています。

- 含むもの
- 1ページの案内サイト（見本どおりの骨格）
- 文字・写真の差し替え、枠の並び替え、色・書体の調整

## セクション：よくある質問

- よくある質問
- 月額ツールとどっちがいい？
- 自分で毎月触り続けたいなら月額ツールも選択肢です。一度つくって終わりに近いなら、この1万円プランが向きます。
- 無料修正は何回？
- 納品後の無料修正は1回までです。それ以降は別料金です。
- 公開URLは .com ですか？
- 独自の .com ドメインそのものは含みません。確認画面でローマ字のパス希望（例：aisin-cafe）を書けます。日本語や記号は使えません。
- もっと凝りたいとき
- フォームやレイアウトの作り直しなどは、おおむね2万円〜の別見積になります。
- パソコンが苦手でも大丈夫？
- はい。分からなくてよい空気で進めてください。迷ったらこのヘルプを見て、注文画面に戻るだけで十分です。

## セクション：確認とZIP

- 確認とZIP
- 保存＝送信ではありません
- 最後の確認で内容をチェックし、ZIPをパソコンに保存します。案内された連絡先に、自分で添付して送ってください。

## セクション：編集ハブ（細かく直す）

- 編集ハブ（細かく直す）
- 編集する
- 並び替えに入ります。色はハニカム。書体は各文字入力の画面で、その役だけ選べます（キャッチ画面ならキャッチ書体のみ）。写真・カードを増やすときは横幅いっぱい／半分を選びます。隙間（狭い／ふつう／広い）も変えられます。⋮⋮ をつかんで順番を変えられます。左の見本は見るだけです。

## セクション：文章の選び方

- 文章の選び方
- 枠ごとの5案
- サンプル本線では、枠ごとに5案から選びます。「別の5案を作り直す」も使えます。

## セクション：画像の入れ方

- 画像の入れ方
- 画像ワイヤー
- サンプル本線では位置の目安（ワイヤー）で写真をはめます。枚数や枠の変更は完成後の「編集する」からできます。

## セクション：色・書体

- 色・書体
- 色の変え方
- 編集ハブではハニカムから色を選びます。サンプル本線では入口の色合い選択が中心で、細かい色編集はハブ側です。
- 書体の選び方
- 文字を直す画面の中で、その役の書体だけ選べます（サイト全体で共通の3役：見出し／キャッチ／本文）。キャッチ見出しの大きさは「キャッチ・文字」の中で変えられます。
