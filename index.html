About

Profile

増渕 敦（Atsushi Masubuchi）

お客様の立場に立って考える Web Designer です。声になっていない要望にも耳を傾け、「何を作りたいか」だけでなく「なぜそれを作りたいのか」まで整理します。

大切にしていること
  • 【使う人基準】見た目の新しさより、触ったときに迷わないかを先に判断する。
  • 【優先順位】全部を同じ強さで出さない。先に伝えることを決めてから並べる。
  • 【統一感】色・見出し・余白のトーンをサイト全体でそろえる。ページごとに印象が割れないこと。
  • 【引き算】足す前に、無くても伝わるかを見る。装飾だけの要素は置かない。
強み
  • 要望を「困りごと」から聞く 作りたい画面から入らず、何に困っているかを先に聞いて、載せる順に分けます。
  • 課題から設計する力 「バイタル記録ノート」は、実際の困りごとから機能・構成・UIを一から構想しました。
  • 実物で判断する 言葉だけで決めず、画面を触ってから直します。このサイトの開閉もその判断です。
ご依頼できること

こんな制作をお受けできます。

  1. 会社・教室の紹介 今見ている、このページのような紹介サイト。
  2. お店・サービスの案内 このウェブサイトと同じレイアウトで、お店の案内に差し替えたもの。
  3. 1枚の案内ページ バイタルの詳細のような、1つの案内に絞ったページ。
  4. 今あるページの直し 今あるサイトを、このページのように見やすくする。
  5. 自分で更新できるサイト このページを、あとから自分で文章や写真を変えられる形にする。
  6. 問い合わせの記入欄 このページの下にある、問い合わせの欄。
料金の目安

プランは3つです。中身と値段をセットにしています。

  1. 1万円 このウェブサイトと同じレイアウト。今見ているページの場所に、お客様が文章と写真を入れる。見比べで番号を見て記入し、PDFで保存するか印刷する。写真の大きさは合わせる。直しは1回。2回目から別料金
  2. 要相談 お客様の希望のホームページ。このレイアウトに限りません
  3. 10万円 今あるサイトを WordPress にする。このウェブサイトと同じ見た目にする必要はありません。使い方の説明まで

1万円のプランに WordPress を足す場合

  1. ＋5万円 すでに WordPress のアカウントがある。このレイアウトを載せる
  2. ＋7万円 まだアカウントがない。使えるようにしてから、このレイアウトを載せる

文章の新規、ロゴ、ページを増やす、ページごとに違うデザインは含みません。

よくある質問
すでに WordPress を使っています。いくらかかりますか？

1万円のプランに ＋5万円です。今お使いの WordPress に、このウェブサイトと同じ見た目と、問い合わせ欄を載せます。

まだ WordPress を使っていません。いくらかかりますか？

1万円のプランに ＋7万円です。使えるようにするところから、このウェブサイトと同じ見た目を載せます。

今あるサイトを WordPress にしたいのですが？

10万円です。今のサイトを、自分で更新できる形にします。このウェブサイトと同じ見た目にする必要はありません。使い方の説明まで含みます。

直しは何回までですか？

1万円のプランは1回までです。2回目から別料金です。ほかのプランは、相談して決めます。

サーバー代は、制作費に含まれますか？

含まれません。月々のサーバー代は、お客様の契約です。セキュリティなども同様です。

ほかのご質問は、お気軽にお問い合わせください。
