# UI役割監査（正式）

- **日付**: 2026-09-13
- **状態**: **確定**
- **一言**: **説明用の部品と、操作用の部品を混ぜない。見た目と役割を一致させる。**

---

## 原則

1. **見た目＝役割**  
   ボタンに見えるならボタン。チェックに見えるならチェック。凡例に見えるなら凡例。
2. **説明は操作を模倣しない**  
   凡例・注記・ラベルは、押せる部品の見た目を流用しない。
3. **一つの意味は一つの表現**  
   「表示中」を☑・緑・文言の三重にしない。
4. **質問**  
   「これは何に見えるか」ではなく、**「本当にその役割なのか」**。

---

## 監査チェック（画面ごと）

| # | 見るもの |
| --- | --- |
| ① | 操作できないものが、操作できそうに見えていないか |
| ② | 凡例・説明が操作部品を模倣していないか |
| ③ | 同じ情報を二重表現していないか |

---

## 適用メモ（2026-09-13）

| 対象 | 対応 |
| --- | --- |
| レイアウト凡例 | ☑☐ 廃止 → `● 表示中`＋説明文（状態説明のみ） |
| 行の表示切替 | 実チェックボックスは操作役として当面残す（凡例とは分離） |
| カード内重心 | ハブ基準にタイトル／説明／上下余白を共通化 |
| 引き算トグル | 検証終了→撤去。引き算見た目を標準化 |
| レイアウト変更中の左プレビュー | 全体Fit（場所一覧と同じ俯瞰） |
| 赤タイトル（細かく自分で作る） | **黒へ変更済**（通常案内） |
| レイアウトFit時の左プレビュー | 薄くしない（ズームのみ）。場所一覧の薄さは維持 |

---

## カード内レイアウト（共通）

Selection系カード（ハブ入口・メニュー項目・案内ポップアップの文言ブロック）:

- タイトル位置・説明との間隔・上下余白を揃える
- 短いタイトル＋説明はカード内の**中央付近**に見えること
- 画面ごと（通常／ポップアップ）で文字位置を変えない
