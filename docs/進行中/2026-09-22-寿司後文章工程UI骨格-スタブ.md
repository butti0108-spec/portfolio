## フロー

色合いのあと → **文章の決め方2択**（入口カード同型）

- **おまかせ** → 基本情報 → **Coolors型レビュー**（左プレビュー＋右：これで進む／もう一度選ぶ／枠ごと鍵）→ 画像
- **キーワード** → 方向1画面（複数・全体1以上）→ 基本情報 → 枠ごと（hero→about→works→contact）3案＋ガチャ → 画像

入力・条件指定（決め方の二択、キーワード、基本情報）は1画面。文章候補を見比べる段階（枠ごと3案、おまかせの見直し）から左＝操作／右＝見本プレビュー。候補クリックで即反映、自動で次枠へ進まない。

### 共通1行案内（文章工程のみ）

文言固定:「あとから、サイト内の文章は修正できます。まずは完成まで進みましょう。」  
決め方2択のあと〜枠／おまかせレビューまで常時。**画像工程には載せない。**

### おまかせ Coolors型

- 左: おまかせで組んだ文が載った見本プレビュー
- 右: 「これで進む」「もう一度選ぶ」（未鍵枠だけ再抽選）／枠ごと鍵（任意）
- 生成は `Sample1manCopyDict`／preset。乱数種は回すたびに変える

## 辞典（工房一本）

| パス | 役割 |
|------|------|
| `sample-1man/copy-dict/meta.json` | axis／section／keyword（方向チップ対応） |
| `sample-1man/copy-dict/presets.json` | おまかせ用・枠ごとの axisId 並び（完成文は持たない） |
| `sample-1man/copy-dict/scenes/*.json` | scene 部品（open／mid／close） |
| `sample-1man/copy-dict-engine.js` | `Sample1manCopyDict`（同オリジン fetch） |

- `sushiSampleKey` 先頭トークン → scene（例 `cafe-warm-a` → `cafe`）。無い scene は cafe へフォールバック
- キーワード: 方向チップ → axis ヒント → **axis を3つ先に選ぶ** → 各 open+mid+close
- おまかせ: preset 1本で枠ごとの axis → 同じ組立（キーワード画面は出さない）
- 3案は **axis 重複禁止**。欠損時はフォールバック文（真っ白にしない）
- **穴埋め（2026-09-22）**: 主要6軸×open/mid/close 各3以上。bright mid/close が全 scene で0だった穴を優先。works/contact の空に近いマスも補充。保証は「確率的にほぼ一致しない」まで
- **固有性**: 生成のたび `freshSalt`（日時+tick）。制作フロー内 `sessionUsedPartIds` で部品IDを優先回避（枯れたら緩和）。フロー開始で reset
- `easy-copy-dict.js` は移行フォールバック。本線は copy-dict 優先
- 旧 `easy-sec-*`（5案）は本線フロー外（HTMLは hidden 維持）
