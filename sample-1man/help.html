    画面の見方・進め方の基本

    入口は2つだけです。「サンプルから選ぶ」か「自分で作る」か。

    最初の入り口（2択）

    初めて開くと、画面全体に入り口が出ます。サンプルから選ぶか自分で作るかを選びます。途中でモードを切り替えるメニューはありません。やり直すときは「最初に戻す」です。

    サンプルから選ぶ（本線）

    1. 回転寿司で見本を見て、「ストック」か「これにします」で1件決めます（ストックは最大3）。
    2. 用途 → 色合い（見本のまま／色だけ変更）を選びます。
    3. 基本情報 → 枠ごとの文章（5案から選ぶ）→ 画像ワイヤー → 作成演出 → 本番プレビュー。
    4. 「これでいい」で確認・ZIPへ。「編集する」で編集ハブへ。

    選択・入力のあいだは本番プレビューを出しません。

    自分で作る

    用途を選んだあと、編集ハブ（並び替え）へ進みます。色・文字・画像・枚数の増減を自分で触れます。

    戻る操作

    • 一つ前の作業に戻す … 直前の編集操作を取り消します。
    • 並びを最初に戻す … 枠の順番だけ初期に戻します。
    • 最初に戻す … 進行データをすべて消し、入り口の2択からやり直します。

    なぜ1万円か

    簡単なホームページを、簡単に

    このプランは「何でも複雑なサイトを安く」ではなく、簡単なホームページを、簡単につくるためのものです。判断材料として、切っている範囲をはっきり見せます。

    月額ツールとの違い

    月額のホームページツールは否定しません。ずっと自分で触りたい人には向きます。こちらは一度つくって納品する形で、フォーム常設や無制限の直し、独自ドメイン運用などは切っています。

    よくある質問

    月額ツールとどっちがいい？

    自分で毎月触り続けたいなら月額ツールも選択肢です。一度つくって終わりに近いなら、この1万円プランが向きます。

    無料修正は何回？

    納品後の無料修正は1回までです。それ以降は別料金です。

    公開URLは .com ですか？

    独自の .com ドメインそのものは含みません。確認画面でローマ字のパス希望（例：aisin-cafe）を書けます。日本語や記号は使えません。

    もっと凝りたいとき

    フォームやレイアウトの作り直しなどは、おおむね2万円〜の別見積になります。

    パソコンが苦手でも大丈夫？

    はい。分からなくてよい空気で進めてください。迷ったらこのヘルプを見て、注文画面に戻るだけで十分です。

    編集ハブ（細かく直す）

    編集する

    並び替えに入ります。色はハニカム。書体は各文字入力の画面で、その役だけ選べます（キャッチ画面ならキャッチ書体のみ）。写真・カードを増やすときは横幅いっぱい／半分を選びます。隙間（狭い／ふつう／広い）も変えられます。⋮⋮ をつかんで順番を変えられます。左の見本は見るだけです。
