# クルハブ同期（確定）

- **日付**: 2026-08-25
- **正本**: Googleドライブ上で更新日時が新しいファイル
- **アプリ**: https://butti0108-spec.github.io/kuru-hub/ （PWA・ホーム画面追加可）

## 流れ

1. クルハブで編集 → **端末に保存**
2. **書き出し** → Driveへ上げる
3. 別端末では Driveから落として **取り込み**
4. スレッドが変わっても、最新ファイルを読めばよい（チャット記憶に依存しない）

## 使わない／任意

- GitHubトークンでの保存は任意
- チャットの要約・圧縮に頼らない

## ポートフォリオ側との同期（追記）

- ポートフォリオの `docs/` を正とする更新は、**GitHub の kuru-hub にも同期（commit / push）**すること。
- ポートフォリオだけ push しても、外からの閲覧用アプリ（Pages）には反映されない。
