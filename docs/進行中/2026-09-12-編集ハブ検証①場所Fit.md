# 編集ハブ検証①：場所から編集（Fit）

- **状態**: 検証実装（採用未決）
- **対象**: 編集ハブのみ
- **触らない**: 見本30・文章・ロゴ・サンプル本線

## 仮説

「場所を選ぶモード」だと、説明なしで理解できるか。

## 手順

1. 入口で「自分で作る」→ 用途 → 編集ハブ  
   （またはサンプル完成後の「編集する」）
2. 右に「場所から編集」が出る
3. 押す → 左プレビューが全体 Fit、編集可セクションが黄枠
4. セクションを押す → 倍率復帰、右に画像／文字／色など
5. 選ぶ → 既存の個別編集へ合流
6. 「やめる」「場所を選び直す」で戻れる

## 判定

- 見れば「場所を選ぶ」と分かったか
- 説明文がなくても次の操作ができたか
