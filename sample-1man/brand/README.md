# Brand assets — アーチデザイン工房

## 正本（見た目の正）

共有画像を外周トリム＋背景透過した PNG を使う。

- `logo-color.png` … カラー一式・透過（ヘッダー／ヘルプ）
- `logo-color.jpeg` / `logo-color-ref.jpeg` … 元画像控え
- `mark-only.png` … マーク切り出し・透過
- `mark-favicon.png` / `favicon-32.png` … ファビコン用・透過

旧SVGは参考残置。表示の正は透過PNG。
