## kuru-hub への反映

この `docs/` を直しただけでは、外からの閲覧アプリには届かない。
**ポートフォリオの push に加えて、kuru-hub へ同期（commit / push）**すること。詳細は [`確定/2026-08-25-Drive同期.md`](./確定/2026-08-25-Drive同期.md)。

---
Cursorのメモリ／チャット履歴とは別に、**決まったこと・TODO・優先・進行中の計画**をここに残す。

## なぜあるか

- スレッドが変わっても、増渕さんもクルも同じ文書を読める
- メモリには「詳細は docs を見よ」だけ書き、毎回の長文思い出しを減らす
- Google連携や専用アプリより、今の作業量ならこの方が軽い
- 行き違い防止（口頭・チャットだけだと忘れる）

## 更新のしかた

1. 議論する → ひと段落したら `運用ボード.md` や `確定/` / `進行中/` を更新
2. **追記・修正があればその都度 commit / push してよい**（2026-08-29 増渕さん合意。都度確認は不要）
3. 項目が増えて見づらくなったら目次WEB化・リンク整理
4. メモリや Cursor ルールは「参照先」だけ維持

**クルへの依頼**: 作業で docs に変更が出たら、気にせず commit → push まで進める（本番WPの公開操作だけは人の最終確認）。
