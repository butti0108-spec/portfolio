## 製品側の色の置き場（参照）

サンプル本線で選びやすい6ムード（`PRESETS`）:

| key | 印象の芯 |
|-----|----------|
| clinic | 白地＋紺（清潔・余白） |
| green | 淡緑地＋深緑（葉・呼吸） |
| cafe | ベージュ地＋茶／暖アクセント（木・朝・麦） |
| ink | 墨地＋金寄りアクセント（夜・カウンター・モノクロ） |
| brick | 暖オレンジ地（窯・提灯・熱） |
| sakura | 淡桜地＋くすみ赤（花・午後・やわらか） |

詳細編集ではハニカムで寄せ可能。**グラデーションは意味があるときだけ**（光・温度・奥行き）。機能があるから使わない。  
グラデ可能スロットは6（`chromeBg` / `pageBg` / `valuesBg` / `accent` / `cardBg` / `contactBg`）。詳細は別紙。
