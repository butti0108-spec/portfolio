# UI分類・全画面棚卸し（メーカーUI／付箋）

- **日付**: 2026-09-13（辞書 Ver0.1・状態語彙に合わせて更新）
- **正本**: `docs/進行中/2026-09-13-UI分類辞書-Ver0.1.md`
- **基準（実装メモ）**: `docs/進行中/2026-09-13-UI分類-候補対応表.md`
- **やり方**: 画面ごとに見える文言・部品へ、候補タグだけ付与（CSS・クラス変更なし）
- **タグ**: `H1候補` `H2候補` `H3候補` `H4候補` `System候補` `Interaction` `Button本線` `Button補助` `Button弱` `Selection Card` `Toggle` `Icon` `対象外` `所属保留` `名称保留`
- **対象外の明示**: 左プレビュー内のサイト本文・写真・お客様向け見出しはすべて `対象外`（生成HP）
- **構成**:
  ```text
  UI分類辞書（正本）
    ↓
  候補対応表（実装メモ）
    ↓
  全画面棚卸し（本ファイル・所在）
  ```

## 0. 共通殻（常時）

| 要素 | 文言例 | 付箋 |
|---|---|---|
| ブランド | アーチデザイン工房 | Interaction / Button弱（リンク）※ブランド扱い保留可 |
| 幅ヒント | スマホ ← タップで切替 → PC | H4候補 または System候補（保留） |
| 幅メタ | タブレット / 768px | System候補 |
| ヘルプ | ヘルプ | Button弱 |
| リセット | 最初に戻す | Button補助（破壊寄り・保留） |
| モバイルタブ | サンプル画面／注文画面 | Toggle |
| 右タイトル | 注文画面／キャッチ文／編集ハブ | H1候補 |
| 再開注意 | 更新・開き直したときは写真を… | System候補 |
| フッタ戻る | 戻る | Button補助 |
| フッタ前進 | 確定／これでOK | Button本線 |
| コーチ | （動的）入力が終わったら下の「確定」を… | System候補（要名称変更） |
| ステータス | （動的） | System候補 |

## 棚卸しで見つかった論点（監査・辞書へ返す）

1. **`step-help` / `entry-howto-note` / `dash-note`** … **所属保留**（Content H4 か System か）
2. **`entry-choice`（用途・色合い）** … **所属保留**（Selection Card か Toggle か）
3. **`char-count`** … **所属保留**
4. **書体カード** … **所属保留**（Selection Card か Toggle か）
5. **コーチ** … System はほぼ確定。**名称保留**（表示名・クラス名）
6. **H5の必要性** … 今回の付箋だけでは必須に見えない（4段階で足りそう）
7. **強調マーカー** … Ver0.1どおり辞書本体には色を入れず、稀用ルールのみ
