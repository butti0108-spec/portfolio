バイタル記録ノート

血圧・脈拍・体重・体温をスマートフォンで記録し、履歴を振り返るための軽量Webアプリです。 家族が毎日続けやすいよう、入力と確認の画面をシンプルに分けています。

アプリを開く GitHub

画面イメージは制作時点のものです。アプリの更新により、実際の画面と異なる場合があります。

担当
企画・画面構成・UIデザイン・コーディング
技術
HTML / CSS / JavaScript、PWA（manifest / service worker）
公開
GitHub ／ デモ

サンプルデータ

架空のデモ用CSVです。アプリの「CSVから戻す」からインポートすると、記録・カレンダー・グラフの動作確認ができます。

デモ用CSVをダウンロード

課題

紙やメモアプリだと続きにくく、数値の推移も見づらい。スマホですぐ付けたい。

工夫した点

  • 「記録する／見る」の2画面に絞り、操作を単純にする
  • スマホ表示を前提に、入力しやすいレイアウトにする
  • ホーム画面追加を見据えたPWA対応
  • CSVでバックアップ／復元できる（下のデモ用CSVで動作確認可）
  • 選択した期間のまとめ・グラフ・測定一覧をPDFとして保存・印刷できる

ポイント

日常の記録に特化したシンプルなUIです。 画面は記録・カレンダー・グラフの3点で概要が伝わるようにしています。
