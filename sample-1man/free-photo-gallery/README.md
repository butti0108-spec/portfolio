## 重要：再配布の線引き

| 種類 | 見本サイトに載せる | 「ご自由にDL」ギャラリー |
|------|-------------------|-------------------------|
| Unsplash系 | 多くの場合OK | **まとめて配布所にするのは不可寄り**（競合ミラー禁止） |
| Flickr（写真ごと） | ライセンス次第 | **CC0／パブリックドメイン等だけ** |
| クル画像生成 | 利用条件確認後 | 条件OKならギャラリーの主戦力にできる |
| color-insert 等 | 見本用資産 | **ギャラリー対象外** |

→ このギャラリーの本線は **「確認済みの再配布可」＋「生成／オリジナル」**。  
Unsplashは「参考リンク」やメーカー内プレビュー用に留め、**ダウンロード棚には載せない**方針。

## カード上寄せ（下トリム）

半幅カードで下半分が帯に隠れる前提の写真は:

1. `approved/` に原板（再配布OK確定）を置く  
2. 上半分中心にトリムした版を `trim-card/` へ（ファイル名例: `01-work-01-upper.jpg`）  
3. ギャラリーUIでは「カード用（下トリム済）」と明示

敦さんの上下調整が終わってから、**approved分だけ**一括トリムする。
