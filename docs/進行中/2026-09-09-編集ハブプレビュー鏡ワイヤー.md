## 役割

| 左 | 右（上から） |
|----|----------------|
| 本番プレビュー | 1. ABC切替（種火） |
| （ドラッグでも並び替え可・後続） | 2. プレビュー表示（幅） |
| | 3. 小さいワイヤー（プレビューの鏡） |

- 主操作は右。左は結果確認＋必要ならドラッグ
- ワイヤー見出しは固定名ではなく、**プレビューに出ている見出し文言をそのまま**
- ABC切替: 骨格だけ入れ替え、**文字・写真・色など中身はすべて残す**
- ABC切替時: 薄い注意ポップ（赤くしない）→ 自分でワイヤー／プレビュー調整
- Undo: レイアウト系操作を一手ずつ戻す（積みを一段はずす）
- 写真追加後: ドラッグで場所変更できる旨を案内
- サンプル本線は触らない
- 表面RPG文言・屋号反映は後回し（分かりやすさ優先）
