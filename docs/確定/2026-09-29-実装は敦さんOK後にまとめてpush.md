# 実装は敦さんOK後にまとめて commit／push

敦さん合意（2026-09-29）。クル／ソル体制の Git 手順を差し替える。

旧手順の詳細控え: [進行中/2026-09-21-ソル運用-実装後commit-push.md](../進行中/2026-09-21-ソル運用-実装後commit-push.md)（**いまは使わない**）

親正本: [2026-09-21-クルソル体制-フェーズ運用](./2026-09-21-クルソル体制-フェーズ運用.md)

---

## なぜ変えたか

1. **細かい修正ごとに push すると時間がかかる**
2. 戻し・直しを push すると、**どの push が正しいのか分からなくなる**

---

## 新しい流れ（変わらない／変わる）

| 順 | 誰 | すること |
|----|-----|----------|
| 1 | クル | 指示を切る（ここは変わらない） |
| 2 | ソル（実装） | 実装 → 自分でブラウザ通し → 安心できるところまで直す。**この段階では commit／push しない** |
| 3 | 敦さん | できているか確認。修正があればその場で指示 → 実装が直す → また確認 |
| 4 | 敦さん | **OK と言った時点**で、まとめて commit／push |
| 5 | クル | push 後の差分と通しを確認 |

## 実装が守ること

- 敦さんの OK が出るまで **commit／push しない**（明示の「commitして」「pushして」も、OK前なら止めて確認）
- 細かい直しのたびに push しない
- 自分の通しと「安心して終われるか」は、これまでどおり必須（OK前の自己確認）
- OK後の一回の commit／push に、その区切りの直しをまとめる
