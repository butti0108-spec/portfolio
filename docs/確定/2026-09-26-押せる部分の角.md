# 押せる部分の角

- **日付**: 2026-09-26
- **状態**: **確定**
- **検索キーワード**: `尖った四角は押さない` ／ `丸ボタン` ／ `角丸`
- **実装**: 画像の操作（`sample-1man/script.js` の開く／閉じる、`sample-1man/sample-overrides.css` の広い編集面とボタンの角）

クルへ確認を頼むときの一言: **「尖った四角は押さない」**

## 決め

工房で押せる部分に、尖った四角は使わない。形は次の2つだけ。

- **丸ボタン** … 短い操作。開く、閉じる、OK、次へ、ヘルプ、拡大、位置の矢印、枚数の＋−のように、「ここを押す」が本体のもの。
- **角丸** … 横に広い選択。自分の画像から選ぶ、ギャラリーから選ぶ、いっぱい、入力欄のように、面を押すもの。押さない枠や、開いた編集のまとまりも角丸。

尖った四角が残るのは、お客様の見本の中だけ。見本サイトの写真や枠は、その店の形なので、工房のボタンとは混ぜない。

アクセントとして、尖った四角のボタンを1つか2つ残すことはしない。
