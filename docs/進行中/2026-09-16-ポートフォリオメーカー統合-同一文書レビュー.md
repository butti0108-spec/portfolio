# ポートフォリオ＋メーカー統合・同一文書レビュー（実装メモ）

- **状態**: 実装着手 2026-09-16
- **方針**: ローカル一体／本番は review 除外／プレビューはメーカー本体を共用

## いま入ったもの

1. `sample-1man/PUBLISH.md` … 本番に含める／含めない一覧
2. `?review=1` … メーカー同一文書で見本レビュー（iframe・外側 scale なし）
   - `review-mode.js` / `review-mode.css`
   - `script.js` の `__sample1manReviewApply`
3. 旧 `review-dash/` … `../index.html?review=1` へ誘導

## 開き方（ローカル）

1. `_dev-server.ps1` または `_static-server.js` でポートフォリオ根を配信
2. `http://127.0.0.1:PORT/sample-1man/index.html?review=1`

## プルプル対策（2026-09-16・review-same-2）

同一文書化後も揺れたため、レビュー中は次を無効化:

- 本体 `applyPreviewFrameScale` の自動 `zoom`（スクロールバー↔幅の往復）
- `window.resize` → 再 `apply`
- `.preview-viewport` の幅 transition

確認モードは実寸＋必要なら横スクロール。全体俯瞰だけ手動で一度 zoom。

加えて draft 適用中に `placePreviewWidthControl` が

- ロゴ横（白文字）
- プレビュー上の肌色レール

を往復していた。レビュー中はロゴ横に固定し、レールは出さない。
