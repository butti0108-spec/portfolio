---

## 第一階層

| 親 | 英語メモ | 役割 |
|---|---|---|
| 読む | Content | 読むための情報。Hierarchy（H1〜H4）を持つ |
| 操作する | Interaction | 操作できることを示す。Button／Selection Card／Toggle 等の親 |
| 状態を知らせる | System | いまの状態・進行・結果・案内を知らせる |

---

## Content

- Hierarchy は **H1／H2／H3／H4** の4段階のみ（Ver0.1で確定）。
- **各段の意味ラベル（画面タイトル等）は未割り当て**。割り当ては監査後。
- コンテンツ連動アイコン（⚠ 等）は文字列と一体で、同じ Hierarchy に追従する。

---

## Interaction

親カテゴリ。下位例:

| 下位 | 役割 |
|---|---|
| Button | 押して前進・戻る・副操作する |
| Selection Card | 大きな択一入口（場所から編集、サンプルから選ぶ 等）。Button ではない |
| Toggle | 載せる／載せない、ラジオ的な択一、開示トグル等 |
| Icon Button | ±、▼ など操作示唆の共通部品 |

### Button の3段（日本語寄り）

| 段 | 役割 |
|---|---|
| 本線 | この画面の主前進（確定、これにします 等） |
| 補助 | 戻る、副操作 |
| 弱操作 | リンク風・弱い操作 |

（設計者用英名 Primary／Secondary／Tertiary と対応可）

---

## System

状態の反馈・案内。例: 進行中、成功、注意／エラー、コーチ（状態説明）。

- **コーチ**は System（文章というより現在状態の説明）。表示名・内部名の見直しは別途可。
