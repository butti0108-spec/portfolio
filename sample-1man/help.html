キーワードを入れると、関係ありそうな項目が出ます。

    画面の見方・進め方の基本
    ← 注文画面に戻る

    入口は2つだけです。「サンプルから選ぶ」か「自分で作る」か。

    最初の入り口（2択）

    初めて開くと、画面全体に入り口が出ます。サンプルから選ぶか自分で作るかを選びます。途中でモードを切り替えるメニューはありません。やり直すときは「最初に戻す」です。

    サンプルから選ぶ（本線）

    1. 回転寿司で見本を見て、「ストック」か「これにします」で1件決めます（ストックは最大3）。
    2. 用途 → 色合い（見本のまま／色だけ変更）を選びます。
    3. 基本情報 → 枠ごとの文章（5案から選ぶ）→ 画像ワイヤー（位置の目安）→ 作成演出 → 本番プレビュー。
    4. 「これでいい」で確認・ZIPへ。「編集する」で編集ハブへ。

    選択・入力のあいだは本番プレビューを出しません。見本はすべてこのメーカーで作成しています。

    自分で作る

    用途を選んだあと、編集ハブ（枠の並び）へ進みます。色・文字・画像・枠の増減を自分で触れます。用途を変えるときは「最初に戻す」からやり直してください。

    戻る操作

    • ひとつ戻る … 直前の画面だけ戻します（全部は消しません）。
    • 最初に戻す … 進行データをすべて消し、入り口の2択からやり直します。

    見本サイトの場所

    PCでは左側、スマホでは「サンプル画面」タブに表示されます。サンプル本線では、作成演出のあとに本番プレビューが出ます。

    確認とZIP

    最後の確認で内容をチェックし、ZIPを保存します。保存＝送信ではありません。案内された連絡先に自分で添付して送ってください。

    文章の選び方
    ← 注文画面に戻る

    枠ごとの5案

    サンプル本線では、キャッチ・紹介・おすすめ・ご連絡など、枠ごとに「どれにしますか」と5案が出ます。選んだ内容に合わせて候補を作ります（意味検索や外部の文章サービスではありません）。「別の5案を作り直す」も使えます。

    画像の入れ方
    ← 注文画面に戻る

    画像ワイヤー

    サンプル本線では、本番見本ではなく位置の目安（ワイヤー）で写真をはめます。キャッチ・写真・カードの3枠です。枚数を増やしたい・枠を変えたい場合は、完成後の「編集する」からできます。

    編集ハブ（細かく直す）
    ← 注文画面に戻る

    編集する

    完成後の「編集する」、または入口の「自分で作る」から、枠の並びに入れます。色の細かい調整はハニカム、書体は「書体を選ぶ」から触れます。画像の±もここです。
