# 編集ハブ：写真・カードの大／小配置

日付: 2026-09-10  
状態: 実装済（横／下二択から置換・見本A寄せ）

## 合意

- 編集ハブのみ。サンプル本線には出さない
- ＋するとき（2枚目以降）は **大きい（L）／小さい（H）** の二択
- 旧「横に増やす／下に増やす」は廃止（内部の growDirs は読み込み時に sizes へ変換可）
- 隙間は従来どおり狭い／ふつう／広い
- 見本は **レイアウトA（全幅）中心**。B／Cは見本では使わない（ハブのABC種火は残してよい）

## ルール

1. 1枚目は開始時 **L**
2. 2枚目を **L** → 縦に L / L
3. 2枚目を **H** → 1枚目も **H** に変わる（横に H | H）
4. 以降も L＝全幅一段、H＝半幅。Hが2つで一行
5. **全幅だけのあとに半分を選ぶ**ときは、前の L は触らず **H|H を新しい行として2枚足す**（例: L L → L L H H）。枠が足りないときは横幅いっぱいで1枚だけ足す
6. **いまの枚数で末尾が一段に1つだけの H** なら、その末尾を **L に強制**（余り隙間防止）。L H H のように組になっている末尾 H は触らない
7. 最終枠（max）へ足すときはポップなしで **L 固定**

## データ

```text
itemLayouts: {
  "about-photos": { sizes: ["L"|"H", ...], gap: "tight"|"normal"|"loose" },
  "works-list": { ... }
}
```

- `sizes.length === count`
- 旧 `growDirs` があって `sizes` が無い場合は変換して表示
