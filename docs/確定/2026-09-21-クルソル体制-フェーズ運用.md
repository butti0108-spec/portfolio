## 2. フェーズ完走（最重要・2026-09-21）

スレッドで「いま熱い話」が上がっても、**進行中の実装フェーズを途中で切り替えない。**

AIは今の会話を最優先にしたくなるが、敦さんとクルの話は、ソル実装の **1〜2個先（または直後）の想定・修正案** であることが多い。熱さでフェーズを飛ばすと分散し、どこまでやったか分からなくなる。

### やり方

1. **いまのフェーズを最後まで完走する**  
   実装 → 自己通し（ブラウザ）→ 直し → commit/push → pending → クル確認（コード＋通し）→ 区切りOK
2. 先の話・気になる修正は **メモに溜めるだけ**（その場でソルの作業を切り替えない）
3. フェーズが終わってから、溜めた話を材料に **次のフェーズを1本だけ** 作る

### 禁止

- 「今しゃべってるから」で別機能へジャンプ
- フェーズ途中で寿司レイアウトと保存フォルダを混ぜる、など横断盛り
- 完了していないのに次フェーズ指示を出す

### 例（保存まわり）

区切り1（保存ゲート）→ 2（ZIP再開）→ 3（フォルダ）が本線なら、途中で寿司見た目の話が出ても **3が終わるまで寿司は次フェーズ待ち**。

## 3. 連絡の三段判断（クル）

その場で選ぶ。

| 判断 | 手段 |
|------|------|
| 対話だけで足りる | チャットのみ（触らない） |
| 一方的な短い伝言 | Driveドキュメント等（左Cursor・右Driveの半々可）。切り取って空にする運用可 |
| 残す／長い／採用・研修・方針・実装指示 | **kurusorumessage**（`pending` / `answered`）または portfolio `docs/` |

共有メモ同期が弱いときは Drive 半々を本線にしてよい。連絡リポは記録・長い指示向き。

## 4. Git と確認

### ソル（毎回）

1. 行動前に対象リポ＋連絡リポを `git pull`
2. 指示範囲だけ実装
3. **ブラウザ通し**（普通の道＋ありえない操作・戻り・連打・変な順・更新など）
4. 表示・動きに問題がないことを確認
5. 同じ区切りで commit → `push origin main`
6. `kurusorumessage` の `pending` に報告（hash・**通しでやったこと**・次は指示待ち）

push されていない変更は、クルからは存在しない。未完了。

### クル（毎回）

1. pending と GitHub 差分を見る
2. **可能なら自分でも同等の通し**（Askなら読み確認＋敦さん／Agentで通し、と明示）
3. OKなら次フェーズ。NGなら直し指示（フェーズは切り替えない）

コードだけ見て「完了」は禁止（2026-09-21・敦さん指摘）。甘い完了は差し戻す。

### 禁止（共通）

- Pages 入口削除（`index.html` 等を消したまま push）
- 秘密・巨大 zip を追跡に入れる
- `docs/確定/` の独断改変（案は進行中）
- force push／git identity の無断変更
- 同時に同じファイルを奪い合う（被りそうなら一回止めて pending に「待ち」）

## 5. 指示書（クル→ソル）に必ず入れるもの

1. 目的（1行）
2. フェーズ名／区切り番号
3. やってよい範囲・触るパス
4. **禁止**（help・確定・Pages・次フェーズなど）
5. 文言（仮なら「仮」と明記）
6. 参照（どの正本・どの既存画面）
7. **完了＝ブラウザ通し必須**（通し項目を列挙）
8. commit/push ＋ pending 報告フォーマット
9. 「次は指示待ち。勝手に次フェーズへ行くな」

---

## 6. 完了の定義

```text
完了 ＝ コードを書いた ＋ 自分でブラウザを触った ＋ 変な操作でも破綻しない
        ＋ commit/push ＋ pending に通し内容を書いた
```

「動くはず」「GitHubに載った」だけでは完了ではない。

## 7. 保存・再開フェーズの例（2026-09-21時点）

| 区切り | 内容 | 状態メモ |
|--------|------|----------|
| 1 | 保存ゲート＋3択＋ハブ注意分岐 | 骨格済 |

詳細の実装指示は区切りごとにクルが都度出す。本表は順序の正。

## 8. 一言まとめ

- **フェーズは完走。熱い話はメモ。次フェーズは終わってから。**
- **ソルは書いて push し、通してから完了。**
- **クルは指示を切り、GitHubと通しで確認する。**
